## Install

Download `LemmeType-X.Y.Z.zip` (or the `.dmg`), open it, and move LemmeType to
Applications. Check the download against `SHA256SUMS`:

```bash
shasum -a 256 LemmeType-X.Y.Z.zip
```

To update from an earlier version, quit LemmeType and replace it. Your settings,
vocabulary, and history stay as they are.

Report a Problem.*
